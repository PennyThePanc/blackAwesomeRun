This is a **VS Impostor : Legacy** mod. It doesnt work on any other engine.

When you have installed the mod, make sure to see if ur folders arent nested. To make sure it isnt, you can just right click the zip file and select "extract here" on Windows. Make sure to drag and drop it into the content folder, which is just the mod folder.
 ![install guide](https://github.com/PennyThePanc/blackAwesomeRun/blob/main/installGuide.png?raw=true)
 
 Also make sure that any mods messing with freeplay menus is disabled, it doesnt break the actual mod but it removes or breaks the portrait in freeplay.
 ![open modsList.txt](https://github.com/PennyThePanc/blackAwesomeRun/blob/main/modListGuide1.png?raw=true)![set whatever freeplay mod to 0, meaning off.](https://github.com/PennyThePanc/blackAwesomeRun/blob/main/modListGuide2.png?raw=true)
